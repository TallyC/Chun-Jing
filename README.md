# 純。淨（Chun-Jing）

> 善用其心，成為更好的人。
> Use the mind well, become a better person.

依《華嚴經．淨行品》而作的生活修行工具：把日常的每個動作，變成一次善用其心的機會。製作：Tally.C

整合自兩個工具（原工具保留不動）：
- 《來生，出家簿》（TallyC/Jingxing-Pin）：淨行、功課、齋戒、讀誦、記錄
- 《淨行初履》（TallyC/Jingxing-Chulu）：一日四境（`si-jing.html`）

## 定位
- 主線是在家生活的淨行；出家相關內容（十六田相、出家的三障、十三難十六遮）放在「出家因緣」頁，選擇性閱讀。
- 「善用其心」出自八十華嚴文殊菩薩答智首菩薩之語；六十華嚴同段作「菩薩成就身、口、意業」。
- 主誦六十華嚴（T09n0278）；一日四境引八十華嚴（T10n0279），皆標版本與願號。

記錄只存在使用者裝置（localStorage，前綴 `chunjing:`；初次使用會讀取《來生，出家簿》既有記錄）。
